# On Duty

병동 근무표를 한 사람의 시점에서 보여주는 모바일 웹 페이지입니다. 지금은 정온유(C팀) 시점으로 설정되어 있습니다.

근무표는 달 단위로 계속 추가할 수 있습니다. 시점도 근무표에 있는 다른 사람으로 바꿀 수 있습니다.

## 화면 구성

- **오른쪽 위 카운트다운:** 다음 근무 출발까지 남은 시간입니다. 출발은 근무 시작 1시간 전으로 계산하고, 근무 중에는 퇴근까지 남은 시간으로 바뀝니다.
- **'나' 줄:** 지금 근무 중인지, 아니라면 오늘 상태와 다음 근무를 보여줍니다.
- **지금 병동:** 현재 시간대에 근무 중인 사람들입니다. 달력 위에 항상 보입니다.
- **달력:** 일요일부터 시작하고 좌우로 스와이프하면 달이 넘어갑니다. 날짜를 누르면 아래 내용이 그 날짜로 바뀝니다.
- **인계 카드:** 인계 받는 사람 → 나 → 인계 주는 사람 순서로 A·B·C팀 전원을 보여줍니다. 같은 팀(C팀) 사람은 맨 앞에 한 테두리로 묶어 크게, 다른 팀 사람은 그 뒤에 작게 붙습니다. 이 묶음 테두리는 사이트의 모든 명단에 똑같이 적용됩니다. '나' 칸에는 같은 근무 동료가 같이 나옵니다.
  - 인계 3칸 오른쪽에 그날 미드(인계 없음)를 세로 칸으로 붙입니다.
  - 카드 아래에는 그날 '기타'(인계에서 빠지는 코드)가 있을 때만 붙습니다. 인계와 상관없는 그날 나머지 근무는 넣지 않습니다.
  - 쉬는 날에는 다음 근무와 그날 병동 전체 명단(데이·이브닝·나이트·미드·기타)을 보여줍니다.
- **원본 근무표:** 원본 사진으로, 옮겨 적은 내용을 크로스 체크하는 용도입니다.

## 근무 규칙

| 근무 | 시간 | 출발 | 인계 받음 | 인계 줌 |
|---|---|---|---|---|
| 데이 D | 07–15시 | 06시 | 전날 나이트 | 같은 날 이브닝 |
| 이브닝 E | 15–23시 | 14시 | 같은 날 데이 | 같은 날 나이트 |
| 나이트 N | 23–07시 | 22시 | 같은 날 이브닝 | 다음 날 데이 |

- 미드(MD)는 인수인계 없이 근무를 돕는 헬퍼라서 인계 대상에서 뺍니다.
- 새벽 00–07시에 나이트 근무 중이면 근무를 시작한 전날 밤 날짜로 봅니다.

## 근무표 코드

| 코드 | 의미 | 사이트에서 처리 |
|---|---|---|
| `D` `E` `N` | 데이 · 이브닝 · 나이트 | 인계 대상 |
| `d` `D1` | 데이 계열 근무 | 데이로 취급 |
| `MD` | 미드 (헬퍼) | 인계 없음, 따로 표시 |
| `/` | 오프 | 쉬는 날 |
| `//` | 원티드 오프 | 쉬는 날 |
| `T2` `T5` | 교육 | 인계 제외, '기타' |
| `H2` | 성장 | 인계 제외, '기타' |
| `DCC` | 당일 입원 센터 | 인계 제외, '기타' |
| `결혼` | 결혼휴가 | 인계 제외, '기타' |

근무표 셀의 배경색(Over, Helper 가능성, 팀변경 등)은 데이터로 옮기지 않습니다.

## 데이터 형식

`index.html` 안의 `const RAW=` 한 줄에 모든 근무표가 들어 있습니다. 달마다 한 덩어리이고, 사람마다 `[이름, 팀, "1일부터 말일까지 코드를 공백으로 구분"]` 형식입니다.

```js
const RAW = {
  "11": [
    ["송하연", "A", "N / / / D D E E ..."],
    ...
  ],
  "12": [ ... ]
};
```

- 한 달 안에서는 코드 개수가 그 달 날짜 수와 같아야 합니다.
- 사람 순서와 팀은 달마다 근무표 순서를 따릅니다. 팀이 바뀌면 그 달 데이터에서 팀 글자만 바꾸면 됩니다.
- 인계 대상은 병동 팀원(A·B·C팀)만입니다. 수간호사·전담·당일 근무자와 출산·육아 휴가자는 넣지 않습니다.

## 다음 달 근무표 추가하기

1. 근무표 원본을 받습니다. 엑셀 파일이 가장 정확하고, 사진이면 옮겨 적은 뒤 반드시 대조합니다.
2. `RAW`에 새 달을 추가합니다. 해가 바뀌면 키를 `"2027-01"`처럼 연도까지 넣는 것을 권장합니다.
3. 원본 사진을 `img/`에 넣습니다. 예: `img/2027-01.png`
4. **대조:** 원본 사진의 칸을 하나씩 잘라 옮겨 적은 값과 나란히 놓고 모든 칸이 일치하는지 확인합니다. 2026년 11–12월은 1,098칸을 이 방법으로 확인했습니다.
5. `main`에 push하면 Cloudflare Pages가 자동으로 다시 배포합니다.

### 처음 한 번은 코드 일반화가 필요합니다

지금 코드는 2026년 11–12월 데이터에 맞춰 몇 군데가 고정돼 있습니다. 새 달을 처음 넣을 때 아래를 `RAW`에서 자동으로 계산하도록 바꾸면, 그다음부터는 데이터와 사진만 추가하면 됩니다.

- **날짜 만들기:** `for (const m of ['11','12'])`와 `new Date(2026, …)`에서 연도·월 목록이 고정돼 있습니다.
- **사람 목록:** `RAW['11']` 기준입니다. 달마다 사람·팀이 다를 수 있으니 그 달 데이터 기준으로 바꿉니다.
- **오늘 판단:** `getFullYear()!==2026`, `new Date(2026,10,1)` 같은 기간 검사가 고정돼 있습니다.
- **달력:** 제목의 `2026년 ${m}월`, 이전·다음 버튼의 `m===11`과 `m===12` 비활성 조건이 고정돼 있습니다. 스와이프는 이미 데이터에 있는 달 목록(`MONTHS`)을 따릅니다.
- **원본 사진:** HTML의 11월·12월 탭과 `img/nov.png`·`img/dec.png` 경로가 고정돼 있습니다. 달 키로 사진 경로와 탭을 만들도록 바꿉니다.
- **안내 문구:** `10월/1월 근무표가 없어요`, `12월 안에 남은 근무 없음`은 데이터의 첫 달·마지막 달에서 계산해서 보여주도록 바꿉니다.

## 다른 사람 시점으로 바꾸기

시점은 `index.html`의 한 줄로 정해집니다.

```js
const ME = '정온유', MY = 'C';   // 나의 이름, 나의 팀
```

`RAW`에 있는 이름과 팀으로 바꾸면 그 사람 기준의 인계·카운트다운·'나' 줄이 됩니다. 근무표 데이터에는 이미 팀원 전원이 들어 있어서 데이터를 새로 넣을 필요는 없습니다.

나중에 여러 사람이 같이 쓰게 할 때 방법은 두 가지입니다.

- **사람마다 따로 배포:** `ME`, `MY`만 바꾼 사본을 사람별 주소로 배포합니다. 가장 간단합니다.
- **한 사이트에서 이름 고르기:** 처음 들어올 때 이름을 고르게 하고, 그 선택을 브라우저에 기억합니다(`localStorage`). `ME`·`MY`를 상수 대신 선택값으로 쓰고, 팀은 `RAW`에서 찾습니다. 헤더의 스위치 로고와 '나' 줄도 선택한 사람 기준으로 바뀌어야 합니다.

근무 바꾸기 요청처럼 여러 사람이 입력하고 그 내용을 저장해야 하는 기능은 정적 사이트만으로는 안 되고, 데이터를 저장할 곳이 따로 필요합니다.
